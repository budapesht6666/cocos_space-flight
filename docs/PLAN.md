## Этап 1 — Вертикальный срез «Ощущение полёта»

Цель: на iPhone в Safari приятно летать и стрелять.

- [x] Настройки проекта: дизайн-разрешение 720×1280 (портрет, fit width); выключены неиспользуемые модули (физика Ammo/Box2D, Spine, DragonBones, terrain, tiled map, video, webview, websocket, marionette, light probes), включён WebGL2. Экспорт конфига сборки и CLI-сборка перенесены на этап 3
- [x] Сцена `Game`: перспективная камера (наклон 70°, горизонтальный FOV 30°, ширина поля 10 юнитов на любом экране), HDR-освещение, bloom + FXAA (`BuiltinPipelineSettings`), туманность (запекается при старте), 3 слоя звёзд с параллаксом
- [x] Конвейер моделей `tools/assets/build-ships.mjs`: расцветка, текстура 512² JPEG, разворот носом в −Z, нормализация размера; Spitfire (Orange), Bob и Dispatcher (Red)
- [x] Корабль игрока: относительный драг (палец не закрывает корабль), клавиатура, ограничения поля по трапеции перспективы, крен, свечение двигателей, мигание при неуязвимости
- [x] `GameWorld` с фиксированным шагом 1/60, пулы, `EventBus`, `SpatialGrid`, `WaveDirector`, framing камеры — в `core/` с unit-тестами (33 теста вместе с валидацией данных и флагов отладки)
- [x] Pulse Cannon с Power I–IV, пули через GPU-инстансинг
- [x] Враги Scout (линия, V, колонна, синусоида-«змейка») и Dart (выход, прицеливание, пике); таймлайн волн по кругу
- [x] Коллизии (круги + сетка), урон, вспышка попадания на враге, смерть врага, таран корабля
- [x] Juice v1: вспышка, огненные шары, искры, обломки, ударная волна-кольцо, тряска камеры, hitstop на крупных взрывах, bloom
- [x] HUD v1: очки, корпус; Game Over и рестарт по тапу
- [x] Отладка: `?debug=1` (FPS, draw calls, сущности, время волн), `?god=1`, `?power=`, `?t=`, `?seed=`, `?slowmo=`
- [x] 👤 Первая проверка на iPhone (Safari и Chrome): «всё неплохо», но 49 FPS — упор в GPU (полноэкранный шейдер туманности на Retina ×3 и bloom)
- [x] Оптимизация под iPhone: туманность запекается в текстуру, 3D в 70% разрешения, bloom 2 прохода; корпус перенесён наверх (внизу закрывал палец и панель FPS)
- [x] 👤 Повторная проверка в превью: Safari 58 FPS с просадками до 44, Chrome iOS 47. Найден баг Dart: пикировал строго вниз (горизонтальная скорость обнулялась) — исправлен, движение врагов вынесено в `core/motion.ts` с тестами
- [x] Релизная web-сборка `web-mobile` из редактора (конфиг `build-configs/web-mobile.json`, portrait, md5 cache), 5.5 MB, ошибок в консоли нет
- [x] 👤 Проверка на iPhone на релизной сборке: Safari и Chrome — в основном 60 FPS, редкие просадки до ~48 на всплесках (взрывы, конец игры); Dart летит как надо. Решение пользователя: качество графики не снижать
- [x] Оптимизация без потери качества: свободные пули и частицы паркуются за кадром вместо переключения `active`

**Готово, когда:** 60 FPS на iPhone в Safari; полёт отзывчивый; взрывы «сочные»; пользователь одобрил ощущения.
