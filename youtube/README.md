# YouTube: материал для Shorts

Ролики для YouTube Shorts снимаются из самой игры: 1080×1920, 60 кадров в секунду игрового времени. Каждый кадр ровный, со звуком игры кадр в кадр. В git лежат скрипты и промпт, отснятое — в `youtube/out/` (git-ignored, пересобирается командами ниже).

## Как пересобрать

```bash
npm run build:web          # релизная сборка, которую снимаем (.cache/cli-game/build/web-mobile)
npm run youtube:capture    # все сегменты из segments.mjs (~10 мин; можно по именам: … -- ice hive)
npm run youtube:mix        # звук каждого сегмента: дорожки и превью со звуком
npm run youtube:cut        # простой Short ≤ 30 с со звуком → out/space-flight-short.mp4
```

Пробный прогон съёмки: `YT_FRAMES=120 npm run youtube:capture -- ice` (не больше 120 кадров на сегмент).

## Как это снято

- **Съёмка** (`capture.mjs`). Скрипт запускает системный Chrome без окна, на видеокарте (ANGLE/D3D11, иначе WebGL программный, а игра падает до уровня `lowest`). Окно 360×640 CSS px × 3, графика `ultra`. Сам скрипт отдаёт сборку локальным сервером.
- Миссия открывается по URL с practice-флагами: `god`, `power=4`, снаряжение, `seed=7`.
- Игру шагают вручную: на каждый кадр ролика — один `GameWorld.update` с dt = 1/60, и сразу скриншот, который уходит в ffmpeg. Поэтому хитстопы, замедление при убийстве босса и HUD идут в игровом времени, как бы медленно ни шла съёмка.
- Корабль ведёт автопилот: держится под нижним врагом или под боссом. Special нажимается на заданных кадрах. До нужного момента (появление босса, босс без брони с малым HP) игра перематывается без съёмки.
- **Звук** во время съёмки не играет: вызовы звуков игры перехватываются и пишутся в лог с номером кадра — эффекты (`playOneShot`), петля луча Ion Laser, треки музыки.
- `mix.mjs` раскладывает по этому логу настоящие файлы игры (`game/assets/resources/audio`) с её громкостями (`data/audio.ts` × настройки по умолчанию).
- Ограничение частоты эффектов (`gap`) применяется в игровом времени. Музыка сводится как в `AudioService`: кроссфейд 1.2 с, интро босса → петля.
- Звуки пушек (в игре по умолчанию выключены, настройка GUN SOUNDS) — отдельной дорожкой, в миксе тише (`GUNS_LEVEL`).
- **События** игры — тоже в лог по кадрам, для монтажа в такт: убийства (размер взрыва, босс, координаты), появление босса, сбитая броня, Nova, лазеры, баннеры WARNING и MISSION COMPLETE, HP босса.

## Что лежит в `out/`

| Путь | Что |
|---|---|
| `clips/<id>.mp4` | сегмент без звука: H.264 1080×1920, 60 к/с, CRF 13 |
| `audio/<id>.music.wav`, `.sfx.wav`, `.guns.wav` | дорожки сегмента с громкостями игры: музыка, эффекты, пушки и дроны |
| `audio/<id>.mix.wav` | все три вместе, пушки тише |
| `preview/<id>.mp4` | сегмент со звуком (−14 LUFS) — послушать |
| `events/<id>.json` | лог: `fps`, `frames`, `sounds`, `events`, `boss` (HP по кадрам), `music`; `f` — кадр клипа |
| `space-flight-short.mp4` | простой Short со звуком, жёсткие склейки, без надписей |
| `space-flight-short.edl.json` | его монтаж: куски клипов и их места |

Сегменты и что в них — `segments.mjs`. Вирусный монтаж с эффектами делается в проекте `C:\projects\claude\remotion-skill` по промпту [REMOTION_PROMPT.md](REMOTION_PROMPT.md).

## Права

Всё в кадре и в звуке — сама игра. Музыка — SketchyLogic «NES Shooter Music» (CC0), эффекты — Kenney (CC0), корабли — Quaternius (CC0), шрифт Orbitron (OFL). Для YouTube претензий быть не должно; авторов можно указать в описании (полный список — `docs/ASSETS.md`).
